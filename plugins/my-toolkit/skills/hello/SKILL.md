# Hello (예시 스킬)

이 스킬이 불렸다면 `my-toolkit` 플러그인이 정상적으로 설치된 것이다.

사용자에게 아래 내용을 한국어로 알려준다:

1. "my-toolkit 플러그인이 정상 동작 중입니다."
2. 이 스킬 파일의 위치: `plugins/my-toolkit/skills/hello/SKILL.md`
3. 새 스킬을 추가하려면 `plugins/my-toolkit/skills/<스킬이름>/SKILL.md`를 만들면 된다는 것
